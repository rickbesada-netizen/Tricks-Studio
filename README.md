# Tricks Studio

Free Windows desktop video editor preview.

**[Download Tricks Studio for Windows](https://github.com/rickbesada-netizen/Tricks-Studio/raw/refs/heads/main/Tricks-Studio-Windows.zip)**

Extract the ZIP, follow the FFmpeg setup in `README.txt`, and launch `TricksStudio.exe`. Use **Install app** to add a Start menu shortcut.

This preview supports video import, clip preview, trimming, splitting, reordering, muting audio, project save and reopen, and 1080p MP4 export. Windows launch and installation have not yet been tested.
