# Tricks Studio

Free Windows desktop video editor preview.

**[Download Tricks Studio Setup](https://github.com/rickbesada-netizen/Tricks-Studio/raw/refs/heads/main/TricksStudioSetup.exe)**

Run `TricksStudioSetup.exe` on Windows 10 or 11 (x64). Setup installs the editor for your Windows account, adds a Start menu shortcut, and opens Tricks Studio. If FFmpeg is missing, setup uses WinGet when available. See [setup instructions](README.txt) for manual FFmpeg setup if needed.

This preview supports video import, clip preview, trimming, splitting, reordering, muting audio, project save and reopen, and 1080p MP4 export. Windows launch and installation have not yet been tested.
